# 使用方法
## yolo-v8(推荐)
```
使用mocs2yolo函数，把json文件转化成对应的.txt文件存储
yolov8_original.pt是官方预训练的权重文件
MOCS.yaml上是网络的设置，包括训练集、验证集、测试集的路径，类别数
```
## 使用说明（已经安装好环境）
```
# 训练
python yolov8.py

```
